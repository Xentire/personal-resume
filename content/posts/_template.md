## 小节标题

正文段落。支持 **粗体**、`行内代码`、[外链](https://example.com) 和裸链接前的普通文字。

- 无序列表第一项
- 无序列表第二项

1. 有序列表第一项
2. 有序列表第二项

> 引用段落，用来看起来像一条提示。

```java
// 代码块，语言名会显示在右上角
public class Demo {
    public static void main(String[] args) {
        System.out.println("hello");
    }
}
```

表格也支持（列表页不需要，长文里对照参数时好用）：

| 项目 | 改造前 | 改造后 |
| --- | --- | --- |
| 首字延迟 | 8s | 1.2s |
| 一次通过率 | 74% | 91% |

### 更小的标题

以上是全部支持的语法；图片暂不渲染（需要时再加）。

文件名的 `_` 前缀（如本文件 `_template.md`）表示草稿/模板，不会被加载。
新建文章时复制本文件，改名为 `my-post.md`，slug 就是 `my-post`，链接是 `/blog/my-post`。
